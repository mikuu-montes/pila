(te va a pedir que coloques tu contraseña)

### 2- Moverse a la carpeta del proyecto:
```

```


## Estructura del repo:
Explicamos que contiene cada archivo:
- ` pila.go `: En este se declara la interfaz de la pila.
- ` pila_dinamica.go `: En este se implementan las primitivas de la interfaz antes declarada.
- ` pila_test.go `: En este se encuentran las pruebas que verifican que lo implementado, funcione efectivamente como un pila.

Para usarse deben tener esta estructura de archivos:

```
tdas/
└── pila/ ← (repositorio actual)
    ├── pila.go
    ├── pila_dinamica.go
    └── pila_test.go

```
